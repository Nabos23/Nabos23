## Verified Systems & Case Studies

### 1. ONE AI — Autonomous Multi-Agent Orchestration Platform

**Custom Python dynamic orchestration engine alongside LangGraph, FastAPI, MongoDB, Redis, and Celery.**

Most AI applications rely on brittle, linear chains that collapse when encountering unexpected tool outputs or complex multi-domain queries. ONE AI decouples orchestration topology from agent definitions, persisting execution state in MongoDB to dynamically resolve agent dispatch arrays, spawn parallel Celery branches, and pause for Human-in-the-Loop review before committing sensitive operations.

* **Dynamic Graph Routing**: Runtime state evaluation determines agent combinations rather than static hardcoded paths.
* **Parallel Branch & Barrier Synchronization**: Celery-backed workers execute concurrent sub-graphs and atomically merge contexts in Redis.
* **Asynchronous HITL Checkpoints**: Graph state serializes to MongoDB with `AWAITING_APPROVAL`, releasing worker threads until review approval.
* **Defensive Tool Execution**: Pydantic schemas enforce type-safe boundaries, eliminating corrupted tool arguments.

**Stack**: `Python` `FastAPI` `LangGraph` `Celery` `Redis` `MongoDB` `Docker` `HITL`

### 2. RentDesk — Autonomous WhatsApp Real Estate & Bookkeeping Agent

**Bi-directional WhatsApp automation assistant linking real-time conversational AI with audited Google Sheets ledgers.**

Landlords spend countless hours manually recording rent transactions from messy, colloquial WhatsApp messages. RentDesk intercepts inbound messages, extracts structured transaction metadata (amount, unit ID, payment method, dates) via defensive LLM parsing, verifies tenant identity, and performs idempotent ledger appends directly into Google Sheets while returning real-time balance statements.

* **Colloquial Entity Extraction**: Parses ambiguous phrases (*"sent 25k for last month and electricity"*) with fallback clarification triggers.
* **Strict Idempotency Guards**: Memory-cached message hashes prevent accidental duplicate credits from network retries.
* **Contextual State Buffering**: Correlates multi-turn messages (e.g., text notification followed by receipt screenshot).
* **Zero New Dashboards**: Keeps property managers in familiar Google Sheets without requiring bespoke CMS adoption.

**Stack**: `Python` `FastAPI` `Meta WhatsApp Cloud API` `Google Sheets API` `Pydantic` `Cloud Webhooks`

### 3. ThriftPulse — Multilingual Voice AI Sneaker Store Operating System

**End-to-end OS for thrift sneaker stores: client-side image compression, dual-write persistence, 80mm thermal shipping slips, and Roman Urdu voice assistant.**

Pre-loved fashion merchants operate in rapid mobile environments plagued by 10MB photo uploads, unindexed stock, and language barriers. ThriftPulse compresses customer photos to ~300KB in the browser via HTML5 Canvas, writes orders concurrently to SQLite and Google Sheets, formats 80mm ESC/POS shipping labels, and provides an omnichannel voice agent understanding Roman Urdu voice notes via Groq Whisper.

* **Client-Side Canvas Compression**: Slashes 10MB mobile camera photos down to <300KB in under 80ms, eliminating server CPU choke.
* **Dual-Write Architecture**: Fast local SQLite async queries for the voice agent paired with real-time Google Sheets syncing for staff.
* **Multilingual Speech AI**: Groq Cloud Whisper (~300ms) with automatic failover to local `faster-whisper` resolving Roman Urdu slang.
* **Driverless Thermal Printing**: Native 80mm roll CSS output allowing direct Bluetooth printing from mobile browsers without desktop drivers.

**Stack**: `Python` `FastAPI` `Groq Whisper` `faster-whisper` `Google Sheets API` `Meta WhatsApp API` `SQLite` `HTML5 Canvas`

### 4. MarketLens — Multi-Source Product Research & Web Intelligence Agent

**Autonomous market research pipeline scraping Daraz, OLX, and search engines, classifying condition tiers, and synthesizing intelligence reports.**

Aggregating product valuations across regional e-commerce stores and classifieds requires manually parsing inconsistent HTML, filtering out spam ads, and segmenting new vs. secondhand pricing spreads. MarketLens coordinates parallel scrapers, normalizes erratic attributes, calculates IQR outlier filters, and feeds clean data into an LLM synthesis engine.

* **Parallel Asynchronous Scraping**: Concurrent crawlers query Daraz, OLX, and DuckDuckGo without cascading network bottlenecks.
* **New vs. Used Classifier**: Heuristic ML layer separates brand-new retail listings from secondhand classifieds.
* **IQR Statistical Modeling**: Deterministic outlier removal calculates true median, quartile ranges, and price elasticity spreads.
* **Structured Intelligence Briefs**: Synthesizes structured markdown briefs outlining pricing discrepancies and marketplace arbitrage opportunities.

**Stack**: `Python` `FastAPI` `Async HTTP` `Pydantic Data Models` `Statistical Modeling` `Marketplace Crawlers`

### 7. WordPress Content & Internal Linking Automation

**End-to-end content automation pipeline powered by LangGraph, ChromaDB, Groq, and Google Gemini with site-scale vector indexing and PageRank authority signals.**

Publishing authoritative content at scale is bottlenecked by topic cannibalization and forgotten internal linking. This system crawls target domain sitemaps, computes a PageRank link graph blended with Google Search Console clicks, embeds article archives in ChromaDB, generates schema-validated markdown drafts, and surgically updates existing legacy posts with natural contextual internal links.

* **Domain-Scale Vector Search**: ChromaDB semantic indexing prevents duplicate coverage and finds complementary parent articles.
* **Authority-Aware PageRank Engine**: NetworkX directed graph analysis scores internal URLs to prioritize high-value linking targets.
* **Surgical Retroactive Updates**: LLM proposes localized paragraph patches with natural anchor text, approved via diff previews.
* **Dual LLM Strategy**: Groq LLaMA for ultra-fast outline and draft synthesis; Gemini for multimodal generation and JSON-LD schema.

**Stack**: `Python` `LangGraph` `ChromaDB` `Google Gemini` `Groq LLaMA` `WordPress REST API` `Google Search Console API`

```text
Business Operations & User Inquiries
 │
 ├── [Ingestion & Validation] (FastAPI / Webhooks / Pydantic Schemas)

 ├── [Dynamic Python Orchestrator] ─── (MongoDB Workflow Graph State)
 │    ├── State Evaluation & Intent Analysis
 │    ├── Dynamic Agent Array Dispatch
 │    ├── Conditional Routing & Multi-Branching
 │    └── Barrier Synchronization / Join Semantics
 │
 ├── [Distributed Asynchronous Workers] (Celery + Redis)
 │    ├── Agent A: Deep Document & Table OCR Extraction
 │    ├── Agent B: ChromaDB Semantic Vector Match
 │    ├── Agent C: External REST Tool & Scraping Execution
 │    └── Agent D: Mathematical & Outlier Analytics
 │
 ├── [Human-in-the-Loop Review Gate]
 │    ├── State Suspension (Status: AWAITING_APPROVAL)
 │    ├── Operator Webhook Notification (Slack / WhatsApp / API)
 │    └── Cryptographic Signature & Resumption Execution
 │
 └── [Verified Output Delivery]
      ├── Idempotent Database Commits (Google Sheets / MongoDB / SQLite)
      ├── Real-Time Voice Synthesis (LiveKit / Cartesia / Whisper)
      └── High-Speed Client Response Delivery
```
